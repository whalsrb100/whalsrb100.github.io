Windows 10 / 11 전용

데이터 복구 이미지 전송 도우미

저장장치를 택배로 보낼 필요 없이, PC에 연결해 복구용 이미지만 안전하게 전송합니다.

recovery-intake.zip 다운로드
설치 과정이 없는 무설치 단일 실행 파일 (recovery-intake.exe)
주의: 복구할 USB·SD카드에는 절대 새 파일을 복사하거나 포맷하지 말고 그대로 연결해 주세요.

진행 순서

  1. 1
    압축 해제 후 실행

    내려받은 recovery-intake.zip 압축을 풀고 recovery-intake.exe를 실행합니다.

  2. 2
    접수번호 발급

    안내 동의 후 접수번호 요청하기를 눌러 이름·연락처·데이터 설명을 입력하면 접수번호가 즉시 발급됩니다.

  3. 3
    장치 선택 및 전송

    복구할 USB·SD카드·외장하드를 선택한 뒤 전송 시작을 누릅니다. (안 보이면 새로고침)

  4. 4
    완료 후 결과 문자 확인

    전송이 끝나면 장치를 뽑으셔도 됩니다. 복구 완료 후 입력하신 번호로 파일 목록과 미리보기 링크를 문자로 보내드립니다.

파란색 'Windows의 PC 보호' 창이 뜰 경우 상용 인증서가 없는 개인 개발 도구라 표시되는 기본 안내입니다.
창 왼쪽의 추가 정보 클릭 → 실행 클릭 → 관리자 권한 허용 예 순서로 진행해 주세요.

알아두실 점

  • 원본 장치는 읽기 전용으로만 열리며, 내부 데이터를 수정하거나 쓰지 않습니다.
  • 내 PC에 임시 이미지 파일을 남기지 않고 압축 스트리밍으로 바로 전송합니다.
  • 용량이 큰 장치는 시간이 걸릴 수 있으니 전송 중 PC가 절전 모드로 전환되지 않게 해주세요.
개인 원격 데이터 복구 지원 안내 · 문의 및 결과 안내는 접수 시 입력하신 휴대폰 문자로 발송됩니다.
