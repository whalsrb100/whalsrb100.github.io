How It Works

접수 진행 순서 (3단계)

복잡한 설치나 회원가입 없이 3분 안에 전송을 시작할 수 있습니다.

1

상담 후 접수 코드 받기

아래 문자 또는 오픈채팅으로 장치 종류와 용량을 알려주시면, 24시간 동안 유효한 전용 8자리 접수 코드를 보내 드립니다.

2

장치 선택 및 코드 입력

접수 프로그램을 실행해 안내에 동의한 뒤, 복구할 USB·SD카드·외장하드를 선택하고 문자로 받은 코드를 입력합니다.

3

전송 완료 후 복구 확인

완료 화면이 뜨면 장치를 안전하게 뽑으셔도 됩니다. 수신된 원본 이미지를 분석해 복구 가능한 파일 목록을 안내해 드립니다.

Safety First

안심하고 맡길 수 있는 이유

장치에 절대 쓰지 않습니다

Windows 물리 장치를 100% 읽기 전용으로만 열어 섹터 단위로 복사하므로, 남아 있는 삭제 데이터가 덮어쓰일 위험이 없습니다.

내 컴퓨터 C 드라이브 자동 제외

Windows가 설치된 시스템 디스크는 선택 목록에 아예 표시되지 않으며, 연결된 이동식·외장 저장장치만 표시됩니다.

고객 PC 용량 사용 0%

PC에 대용량 이미지 파일을 따로 저장하지 않고, 메모리에서 실시간 압축(zstd)하며 암호화(HTTPS) 채널로 바로 전송합니다.

배드 섹터 우회 및 SHA-256 검증

읽기 오류가 난 구간은 섹터 단위로 재시도해 최대한 살려내고, 원본 전체의 SHA-256 해시로 전송 무결성을 검증합니다.

FAQ

자주 묻는 질문

아니요. 인터넷이 일시적으로 끊겨도 프로그램이 자동으로 재연결을 시도하며, 서버가 마지막으로 받은 위치부터 그대로 이어서 올립니다.
삭제된 영역까지 포함해 저장장치 전체를 원본 그대로 읽으려면 Windows 정책상 관리자 권한이 필수입니다. SmartScreen 안내가 뜰 경우 [추가 정보] → [실행]을 눌러 진행해 주세요.
