데이터 복구 이미지 전송 도우미

거창한 복구 업체 홈페이지는 아니고, 지인이나 요청하신 분들 USB·SD카드·외장하드 데이터 복구를 원격으로 도와드리려고 직접 만든 작은 프로그램 안내 페이지입니다.
저장장치를 택배로 보내지 않고, PC에 꽂은 상태에서 복구용 이미지 파일만 안전하게 넘겨주실 수 있습니다.

1. 전송 프로그램 내려받기 (Windows 10 / 11 전용)
recovery-intake.zip 다운로드
* 설치 과정이 없는 단일 실행 파일(recovery-intake.exe)이 들어 있습니다.
※ 진행 전 꼭 지켜주세요
실수로 파일을 지웠거나 포맷 메시지가 뜨는 USB·SD카드에는 절대 새 파일을 복사하거나 포맷하지 마세요. 그대로 두셔야 데이터가 덮어쓰이지 않아 복구될 확률이 높습니다.

2. 사용 순서

  1. 압축 풀기 및 실행
    내려받은 recovery-intake.zip 파일의 압축을 풀고, 안에 있는 recovery-intake.exe를 더블클릭해 실행합니다.
    파란색 [Windows의 PC 보호] 창이 뜰 경우
    개인이 만든 프로그램이라 상용 인증서가 없어서 뜨는 안내입니다.
    창 왼쪽의 추가 정보 글자를 먼저 누르신 뒤, 아래에 나타나는 실행 버튼을 눌러 주세요.
    이어서 뜨는 관리자 권한 허용 창에서도 [예]를 눌러 주시면 됩니다.
  2. 안내 확인 및 동의
    첫 화면의 안내 내용을 확인하신 뒤 체크박스를 선택하고 다음 → 버튼을 누릅니다.
  3. 접수번호 발급받기 (미리 받으실 필요 없음)
    장치 선택 화면 아래쪽의 접수번호 요청하기 버튼을 누릅니다.
    이름, 휴대폰 번호, 복구할 데이터 설명(필수)과 발생 증상(선택)을 적고 접수번호 발급받기를 누르면 접수번호가 바로 발급되어 입력칸에 자동으로 들어갑니다.
  4. 복구할 장치 선택 후 전송 시작
    위쪽 목록에서 복구할 USB, SD카드, 외장하드를 클릭해 선택합니다. (방금 꽂아서 안 보이면 새로고침 클릭)
    장치가 선택된 상태에서 전송 시작 버튼을 누르면 전송이 시작됩니다.
  5. 전송 완료 및 결과 문자 안내
    완료 화면이 나오면 창을 닫고 장치를 뽑으셔도 됩니다.
    제가 전달받은 이미지를 확인해 복구 작업을 마친 뒤, 적어주신 휴대폰 번호로 복구된 파일 목록과 이미지 미리보기 링크를 문자로 보내드립니다.

3. 참고 사항

  • 원본 저장장치는 읽기 전용으로만 열리며, 장치 내부에는 아무것도 쓰거나 수정하지 않습니다.
  • 고객님 PC 하드디스크에 임시 이미지 파일을 쌓아두지 않고 바로 압축 전송합니다.
  • 용량이 큰 외장하드나 SD카드는 전송에 시간이 꽤 걸릴 수 있으니, 전송 중에는 PC가 절전 모드로 꺼지지 않게 해주세요.
  • 도중에 오류가 나면 바탕화면에 오류 로그 파일이 자동 저장됩니다. 그 파일만 전달해 주시면 원인을 바로 확인할 수 있습니다.
개인 데이터 복구 지원용 안내 페이지 · 문의 및 결과 안내는 접수 시 입력하신 휴대폰 문자로 드립니다.
